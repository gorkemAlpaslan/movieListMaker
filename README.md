# movieListMaker

> Early 2022 frontend fundamentals project — an interactive movie list & rating UI.

## Overview
A lightweight browser interface that lets users add movies with a title, poster image URL, and personal rating to build a custom watchlist.

## Tech Stack
- **HTML5** & **CSS3**
- **Vanilla JavaScript**

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/gorkemAlpaslan/movieListMaker.git
   ```
2. Open `movieListMaker/index.html` in your browser.
